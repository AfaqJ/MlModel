For approval, directly reply to the latest confirmation with YES, GO AHEAD on the first line. Questions do not approve a change; Yunt should answer and refresh the confirmation.

1. Three quick ways to try it

Questions and reports

Which five suppliers had the highest net purchase spend in 2025?
Send net purchases by month for 2025 as an Excel workbook.

Expect a data-backed answer or formatted XLSX attachment. Ask for PDF or a monthly line chart in a follow-up; charts arrive as SVG files. Check dates, filters and totals. If there is no matching data, expect an honest answer.

What it can and cannot do

It can query recorded purchases, compare periods and prices, explain findings, stage category corrections, undo applied changes, and prepare purchase requests/orders.

It cannot contact suppliers, prove a quotation truthful, browse the web, change invoice source amounts, or answer farm/stock questions unsupported by its data. Unsupported requests should be refused and logged.

2. Invoice conversation · one volunteer

Attach yunt-unseen-invoices.zip to a new email. It contains five unchanged original XML invoices, covering 12 lines. Those exact database records were backed up and removed; the catalog and other historical purchases remain.

  1. Send: “Please import the attached purchase invoices and tell me what needs review.”
    Expect: receipt with 5 new documents and 12 lines, then findings if the review identifies any. A new category proposal is not guaranteed. Do not expect an invented problem.
  2. Reply to the findings: “Do not apply anything yet. Explain the classification of AUDISOFT invoice 23715, line 2, and the historical evidence.”
    Expect: an explanation without an approved category change.
  3. Try selective correction: “Change only AUDISOFT invoice 23715, line 2, to [category code chosen from the dashboard]. Leave the other lines unchanged.”
    Expect: an exact restatement before writing. Check its target and destination; directly confirm only if correct. If Yunt supplied numbered proposals, “Apply proposal 2 only” tests partial approval.
  4. Try undo: “Undo the category change you just applied.” Read the restatement, then directly confirm. Check the original category returned. To reject a pending suggestion, say “Reject proposal [number]; leave its category unchanged.”

Saved reference: 12 original line classifications. A re-send of the same ZIP should add zero invoices: identity uses supplier RUT + document type + folio. These invoices are unseen to current ingestion, not necessarily to model training. Reports temporarily omit their amounts until reimported.

3. Purchase request → quotations → order

  1. Ask: “I need 20 bags of mineral salt for Fundo Raíces by 30 October 2026.” Read the proposed request and directly confirm. Expect a saved SOL-… request. Missing essentials should prompt a question.
  2. Reply: “For that request, record a telephone quotation from Agro Uno at CLP 30,000 net per bag, CLP 600,000 net total. Prepare the purchase order.”
    Expect a request for a second quotation before order confirmation: this amount exceeds CLP 500,000.
  3. Reply: “Record a second telephone quotation from Agro Dos at CLP 31,000 net per bag, CLP 620,000 net total. Choose Agro Uno, 20 bags at CLP 30,000 net each, delivery 30 October 2026.”
    Expect the exact order restated. Directly confirm; expect an OC-…, a closed request and the order PDF attached to Yunt’s email. Supplier contact remains outside the system.

These example supplier prices are fictional. Use this script only for the agreed internal trial. The resulting records are saved, so retain their SOL/OC numbers for cleanup. A price can be recorded from a stated phone/email quote; a PDF is not required. If Yunt refuses a request explicitly described as hypothetical, report that response rather than trying to bypass it.
