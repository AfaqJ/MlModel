### 2. Item catalog page is slow

data layer src/lib/items/queries.ts and src/lib/items/group.ts.
Find the actual cause with evidence, not a guess. Check specifically:

### 3. Analytics shows ~3,500 items but the catalog table has ~4,000

    src/lib/analytics/queries.ts + aggregate.ts
  - the catalog count: src/lib/items/queries.ts

  - PostgREST default row cap (1,000) or a Supabase `max-rows` setting silently

  - a `.limit()` or `.range()` hard-coded somewhere
  - a filter applied to one path but not the other (date range, decision,
    transaction_type COMPRAS/VENTAS, active/deleted flag)

    migration made these differ)
